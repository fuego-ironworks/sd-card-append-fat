# Vienna identification log

Strong current candidate: **MARS — Maintainable Real-Time System**, associated with Hermann Kopetz and Technische Universität Wien.

See `../mars-tu-wien/README.md`.

Evidence for the match:
- MARS is explicitly described in operating-systems teaching material as a TU Vienna research operating system;
- the second academic MARS prototype was developed at Technische Universität Wien and operational by 1988;
- there is a 1989 paper titled *The Real-Time Operating System of MARS*.

This is not treated as certain because the remembered clue was only "another one developed in Vienna." Keep this directory as the identification ledger until confirmed.

SkyOS is Austrian but is tracked separately under `../skyos/`; the Vienna clue fits MARS much more specifically.
