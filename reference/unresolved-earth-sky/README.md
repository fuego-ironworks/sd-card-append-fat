# Earth / Sky identification log

This directory preserves the original spoken-reference ambiguity while pointing to the current candidates.

## Earth

Strong identification: **EGOS-2000 — Earth and Grass Operating System**.

See `../egos-2000/README.md`.

Why the match is strong:
- the project explicitly expands EGOS as Earth and Grass Operating System;
- it is a teaching OS intentionally kept around 2,000 lines;
- its Earth layer contains the disk-device interface;
- its application layer contains the filesystem.

## Sky

Strong candidate: **SkyOS**, by Robert Szeleney.

See `../skyos/README.md`.

Why it is relevant:
- historical SkyOS descriptions list FAT12/16/32 support;
- it had a VFS with several filesystem implementations;
- OpenBFS was ported to become SkyFS.

These identifications are recorded as candidates so the original wording is not lost. If another "Earth" or "Sky" system is identified later, add it rather than rewriting history.
